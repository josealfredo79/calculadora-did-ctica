# Calculadora Didáctica

Una calculadora interactiva diseñada para propósitos educativos. Permite realizar operaciones matemáticas básicas y sirve como ejemplo para aprender sobre desarrollo web, pruebas y buenas prácticas de programación.

## Características
- Suma, resta, multiplicación y división
- Interfaz sencilla y amigable
- Código modular y fácil de entender
- Pruebas automatizadas incluidas


## Archivos principales
- `index.html`: Interfaz principal de la calculadora y tutorial de uso
- `app.js`: Lógica de la aplicación
- `math.js`: Funciones matemáticas
- `math.test.js`: Pruebas automatizadas
- `style.css`: Estilos de la calculadora

## Uso
1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. ¡Empieza a calcular!

## Pruebas
Puedes ejecutar las pruebas con Node.js usando:

```bash
node math.test.js
```
